Adding the feed

Google Calendar: Other calendars → + → From URL, paste the link. Outlook.com: Add calendar → Subscribe from web, paste the link. Apple Calendar: File → New Calendar Subscription. Some apps prefer a webcal:// link — take the URL above and swap https:// for webcal://.

These services decide for themselves how often to refresh, commonly every few hours and sometimes as much as a day; that delay is theirs and nothing here can shorten it. For changes you want to see straight away, use CalDAV access instead — a feed link is read-only in any case.
